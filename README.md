# Build the Dream Limerick XV

A "Build the Dream XV" style wheel-spin draft game, themed around Limerick senior
hurling from 1990 to 2026.

## How it works

1. Spin the wheel for each of the 15 starting positions on a hurling team, from
   goalkeeper to full-forward.
2. Every spin lands on a real Limerick hurler from a single season between 1990 and
   2026, along with how that year's championship campaign went.
3. Once your Dream XV is complete, simulate a championship run through the rounds
   to the All-Ireland Final and see whether your team can bring home Liam MacCarthy.

Squads are inspired by real Limerick senior hurling panels from each era. Exact
lineups, positions and player ratings are approximated for gameplay balance only.

## Development

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run lint     # run eslint
```

Built with React, TypeScript, Vite and Tailwind CSS.
